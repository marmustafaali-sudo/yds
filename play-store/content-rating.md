Play Console → **Uygulama içeriği → İçerik derecelendirmesi**.
E-posta: `mar.mustafa.ali@gmail.com`

## Uygulama kategorisi
**Yardımcı program, üretkenlik, iletişim veya diğer** → (eğitim/referans uygulaması)

## Sorular

| Soru | Cevap |
|---|---|
| Şiddet (gerçekçi / karikatür / fantezi) | Hayır |
| Korku / ürkütücü içerik | Hayır |
| Cinsellik veya çıplaklık | Hayır |
| Küfür / kaba dil | Hayır |
| Kontrollü maddeler (uyuşturucu, alkol, tütün) referansı | Hayır |
| Kumar (gerçek veya simüle edilmiş) | Hayır |
| Kullanıcılar birbiriyle iletişim kurabiliyor mu (sohbet, mesaj) | Hayır |
| Kullanıcı tarafından oluşturulan içerik paylaşılıyor mu | Hayır |
| Kullanıcının konumu paylaşılıyor mu | Hayır |
| Uygulama kullanıcının satın alma yapmasına izin veriyor mu | Hayır |
| Dijital ürün / para birimi satışı | Hayır |
| Web tarayıcısı içeriyor / rastgele internet içeriği gösteriyor mu | Hayır (yalnızca paketlenmiş yerel içerik) |
| Reklam gösteriyor mu | Hayır |

> Testteki "puan / seri (streak)" mekaniği bir oyun skorudur; bahis, jeton veya
> şans oyunu öğesi içermez → kumar **değil**.

## Beklenen sonuç
Tüm bölgelerde en düşük yaş sınıfı: **Herkes / 3+ / PEGI 3 / ESRB Everyone**.
